# Installation

import { PackageManagerTabs } from '@theme';

<PackageManagerTabs command="install react-native-plain-text" />

This is a native module, so you need to rebuild the app.

Requires React Native's New Architecture (Fabric).

## Usage

```jsx
import { PlainText } from 'react-native-plain-text';

<PlainText style={{ fontSize: 16 }}>Hello there 👋</PlainText>;
```

## Unified `Text` component

For an easy adoption path that doesn't require touching existing `<Text>` call sites,
import `Text` instead of `PlainText`:

```jsx
import { Text } from 'react-native-plain-text';

<Text style={{ fontSize: 16 }}>Hello there 👋</Text>;
```

It's a selector component: `PlainText` for simple strings, falling back to RN `<Text>`
for anything `PlainText` doesn't support (nested text, element children). See the
[`Text` component guide](./text-component) for how it decides and how to build the same
pattern into your own centralized Text component.

Using `PlainText` directly still gives you the best performance.
